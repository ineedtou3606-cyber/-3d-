사록 — 역사 영상 스튜디오 (Windows 10/11, 64비트)

1. ZIP 파일을 폴더 전체로 압축 해제합니다.
2. Sarok.exe를 더블클릭합니다.
3. 기본 브라우저에서 사록이 열립니다. 별도 Python 설치는 필요 없습니다.
4. 대한민국 역사·이솝 이야기·직접 입력 중 유형을 선택합니다.
5. 예시 대본을 넣거나 원하는 이야기를 직접 작성합니다.
6. 실사·3D·역사 만화 중 스타일과 기본·표준·고품질 중 화질을 선택합니다.
7. 장면 프롬프트 만들기를 누릅니다.

이야기 백과사전이 아니라 대본 입력 기반 프로그램입니다.
원하는 한국사·우화 대본을 직접 넣어 사용할 수 있습니다.
화질은 세부 표현 수준을 선택합니다. 자동 생성 출력은 1536×864입니다.

무료 수동 이미지 작업:
프롬프트 복사 → Google Flow 등에서 이미지 생성 → 이미지 가져오기.
Flow의 무료 제공 범위는 계정 및 요금제에 따릅니다.

앱 내 자동 생성:
OpenAI API 키가 필요하며 API 사용 요금이 발생합니다.
윈도우의 사용자 환경 변수 SAROK_IMAGE_API_KEY에 키를 설정한 뒤 앱을 다시 실행하세요.
키를 채팅이나 공유 파일에 넣지 마세요.

종료: 실행 창에서 Ctrl+C를 누르거나 실행 창을 닫으세요.
브라우저 탭만 닫으면 앱 서버는 종료되지 않습니다.
이미지는 창을 닫거나 새로고침하기 전에 다운로드로 보관하세요.

중요:
- Sarok.exe와 app, runtime 폴더를 함께 유지하세요. exe 파일만 옮기면 실행되지 않습니다.
- 3D 스타일은 이미지이며 회전 가능한 3D 모델 파일은 아닙니다.
- 이 배포본은 리눅스에서 윈도우용으로 크로스 컴파일했습니다.
  실제 윈도우 PC에서의 실행 검증은 아직 수행하지 않았습니다.
