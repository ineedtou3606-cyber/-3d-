## 윈도우 프로그램

배포 ZIP의 전체 폴더를 압축 해제하고 `Sarok.exe`를 실행하면 기본 브라우저에서 앱이 열립니다. Python 런타임을 포함하므로 별도 설치가 필요 없습니다. `runtime`과 `app` 폴더를 exe와 함께 유지하세요. 실행 창에서 Ctrl+C를 누르면 종료됩니다. Windows 10/11 x64 대상이며, 리눅스에서 크로스 컴파일한 배포본은 실제 Windows PC 실행 검증을 별도로 해야 합니다.

소스에서 단일 실행 파일을 만들려면 Windows에 Python 3을 설치한 뒤 `build-windows.bat`를 실행하세요. PyInstaller가 `dist/Sarok.exe`를 만듭니다. 빌드는 반드시 대상 운영체제에서 실행합니다.

## 실행

Python 3과 Node.js 24 환경에서 사용합니다.

```sh
cd /workspace/-3d-
python3 -m pip install -r requirements.txt
npm run dev
```

기본 포트는 3000입니다. `npm test`로 대본 보존·스타일 선택 및 이미지 API 어댑터 테스트를 실행합니다. API 테스트는 모의 응답을 사용하며 실제 이미지 서비스 호출은 별도입니다. 정적 HTTP 서버 대신 `server.py`를 실행해야 이미지 API가 동작합니다.

대본을 입력하거나 예시를 불러온 뒤 장면 프롬프트를 생성하세요. 세 탭에서 결과를 복사하거나 전체 Markdown 파일을 내려받을 수 있습니다. 최근 생성에 사용한 입력은 브라우저의 localStorage에 저장됩니다.

## 이미지 사용 방법

- 수동 방식: 프롬프트를 복사해 Google Flow 등의 도구에서 이미지를 만든 뒤 해당 장면의 **이미지 가져오기**로 불러옵니다. 이 앱에서는 API 요금이 발생하지 않습니다. 외부 도구의 무료 범위와 요금은 사용자의 계정·요금제에 따릅니다.
- 자동 생성: 서버 환경 변수 `SAROK_IMAGE_API_KEY`에 OpenAI API 키를 안전하게 연결합니다. 클라우드에서는 환경 설정의 선택적 비밀값으로 입력하며 채팅이나 소스 코드에 키를 넣지 마세요. `api.openai.com`의 HTTPS 접근과 이미지 모델 사용 권한·잔액이 필요합니다. API 호출은 유료입니다.
- **모든 원본 이미지 생성**은 아직 이미지가 없는 장면만 순서대로 요청합니다. 개별 장면 생성·재생성도 가능합니다. 실패하면 멈추며 완료된 이미지는 유지됩니다. 중단 버튼은 현재 API 요청이 끝난 후 다음 장면부터 중단합니다.
- **인포그래픽 편집** 탭은 해당 장면의 원본 이미지를 서버에 전달해 개별 편집합니다. 편집도 별도 과금됩니다. 생성형 편집이므로 대상·한글·구도를 검토하세요.
- 모델은 `gpt-image-1`입니다. 선택한 기본·표준·고품질은 각각 API의 low·medium·high에 대응합니다. 고품질은 비용과 시간이 늘어날 수 있습니다. 원본 생성 출력은 중앙을 1536×864(16:9)로 잘라 표시합니다. 화질 옵션은 세부 표현 수준이며 해상도를 바꾸는 옵션은 아닙니다. 원본 편집은 원본 비율에 맞춰 중앙을 자릅니다.
- 이미지는 브라우저 메모리에만 보관됩니다. 새 장면 생성·새로고침·탭 종료 전에 개별 다운로드로 보관하세요. 원본을 교체하면 기존 인포그래픽 결과는 삭제됩니다.

서버는 개인 개발 환경용입니다. 외부 공개 배포 전에는 사용자 인증과 사용자별 사용량 제한을 추가해야 합니다. 키는 서버에서만 사용하며 브라우저에 반환하지 않습니다.

영상 길이에 맞춰 장면을 균등하게 나누므로 문장 중간이 분리될 수 있습니다. 내레이션 타이밍과 시대 고증은 최종 제작 전에 확인하세요. Flow 소스는 장면당 8초이며 최종 편집에서는 표시된 길이에 맞게 잘라 사용합니다.
